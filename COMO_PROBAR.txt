=====================================================================
  COMO PROBAR EL PROTOTIPO  -  4 PASOS
=====================================================================

  El prototipo analiza una FOTOGRAFIA que usted selecciona. No usa
  camara. Esa decision es de esta etapa: el objetivo es validar el
  algoritmo de forma reproducible. La captura en vivo corresponde a
  la siguiente etapa, sobre telefono movil.


  PASO 1     Abrir la carpeta en Visual Studio Code
  ------     Archivo  ->  Abrir carpeta  ->  ProyectoBilletes

             Correcto si en el panel izquierdo ve:
                 src    datos    scripts    informe


  PASO 2     Abrir la terminal
  ------     Terminal  ->  Nueva terminal

             Comprobar que esta en el sitio correcto:

                 dir src\prototipo_pc.py

             Debe listar el archivo. Si no, repita el PASO 1.


  PASO 3     Instalar las librerias  (solo la primera vez)
  ------
                 pip install -r requirements.txt

             Son tres: numpy, Pillow y matplotlib.


  PASO 4     Ejecutar
  ------
                 python src\prototipo_pc.py


=====================================================================
  COMO USARLO
=====================================================================

  Al abrirse, el panel derecho trae una lista de EJEMPLOS del banco
  de datos. Haga doble clic en cualquiera y lo analiza de inmediato.
  Es la forma mas rapida de demostrarlo.

  Para una fotografia propia, pulse "Seleccionar imagen".

  La fotografia debe cumplir:
     - billete plano, sin dobleces
     - tomada de frente, desde arriba
     - billete entero, con margen alrededor
     - fondo liso y de color distinto al billete

  Botones:
     Seleccionar imagen   abre el explorador de archivos   (tecla O)
     Analizar otra        vuelve al estado inicial         (tecla N)
     Repetir voz          relee el ultimo resultado

  La ventana muestra la fotografia original arriba y el billete ya
  rectificado al marco canonico abajo, mas el diagnostico numerico
  en el panel derecho.


=====================================================================
  RESPUESTAS POSIBLES
=====================================================================

  "No se detectaron anomalias de impresion"   sin senales de copia
  "Posible reproduccion impresa"              senales de copia
  "La fotografia no es utilizable"            pide otra fotografia

  La tercera NO es un error. La rectificacion supone un billete
  plano; si la relacion de aspecto medida se aleja de la nominal
  (140:66 = 2.12), el sistema prefiere pedir otra fotografia antes
  que dictaminar sobre una imagen que no puede rectificar bien.


=====================================================================
  SIN INTERFAZ GRAFICA
=====================================================================

  Para verificar desde la terminal, sin abrir ventana:

     python src\prototipo_pc.py --imagen datos\autentico\50mil\IMG_2198.jpg
        ->  ESTADO: OK        holgura x15.54

     python src\prototipo_pc.py --imagen datos\reproduccion\50mil\50mil_D01_S24FE_tenue_blanco_anverso.jpg
        ->  ESTADO: ALERTA    holgura x0.40


=====================================================================
  SI ALGO FALLA
=====================================================================

  "can't open file"          -> la terminal esta en otra carpeta.
                                Repita los pasos 1 y 2.

  "No module named tkinter"  -> reinstale Python desde python.org
                                marcando la opcion tcl/tk.
                                Linux: sudo apt install python3-tk
                                Mientras tanto use el modo --imagen.

  Error rojo largo al        -> su Python es muy reciente. Instale
  instalar, con                Python 3.12 desde python.org y use:
  "building wheel"                 py -3.12 -m pip install -r requirements.txt
  o "Visual C++"                   py -3.12 src\prototipo_pc.py


  Nota: no hay paso de entrenamiento ni archivo de modelo. El sistema
  usa reglas fijas escritas en src\pdi\reglas.py, asi que se ejecuta
  directamente.
